# PFinanceTracker
My project will be a python-based personal finance tracker that helps users record and track their income and expenses. It will also compare the spending based on category budgets and help users plan their savings. Personal finance tracker uses numerical formulas and compound growth equations. 

## Run

From the repository root:

```bash
python PFinance_Tracker.py
```

`PFinanceTracker.py` is also available as a compatibility entry point:

```bash
python PFinanceTracker.py
```
